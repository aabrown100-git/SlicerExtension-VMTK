# Level Set Segmentation

This module segments the lumen of a *single vessel branch* from an image using a level set method. It is the classic VMTK segmentation pipeline: an initial surface is built inside the vessel, then that surface is evolved so that it settles on the intensity ridges of the vessel wall.

To segment a complete vessel tree, either run the module once per branch, or use Slicer's Segment Editor module (for example its *Flood filling* or *Grow from seeds* effects), which is usually more convenient for multi-branch trees.

## Inputs and outputs

- `Input Volume`: the original image (contrast-enhanced CT or MR angiogram). This should always be the original image, not a vesselness volume, because the surface evolution relies on the real image gradients.
- `Vesselness Volume` (optional): the output of the [Vesselness Filtering](VesselnessFiltering.md) module. When given, it is used for the initialization step instead of the original image, which makes initialization much more robust in low-contrast or noisy data.
- `Seeds`: a markups point list defining the vessel branch to segment. Only the first and last point of the list are used: they are the two ends of the branch. Place them in the middle of the contrasted lumen.
- `Stoppers` (optional): a markups point list marking places the segmentation must not reach. Whenever a stopper is reached, propagation stops there. Use them to prevent leakage into an adjacent vein or chamber.
- `Output Labelmap`: the segmented lumen as a labelmap volume.
- `Output Model`: the surface of the segmented lumen, generated by marching cubes. This model is the input of the [Extract Centerline](ExtractCenterline.md) module.

## How it works

The segmentation runs in two steps:

**Initialization** builds a coarse starting surface between the seed points using a colliding fronts method: two fronts propagate from the two ends of the branch through voxels inside the `Thresholding` range, and the region where they meet becomes the initial surface. This is why the seeds must be at the ends of the branch and inside the lumen, and why the threshold range matters most for this step.

**Evolution** deforms the initial surface using geodesic active contours on the original image, so that it converges onto the vessel wall.

Clicking `Preview` performs the initialization only, which is fast and lets the threshold range be verified before committing to the full computation. Clicking `Start` performs initialization followed by evolution and produces the final labelmap and model.

## Parameters

- `Thresholding`: the intensity range considered to be inside the vessel. The slider range is initialized from the scalar range of the selected input (the vesselness volume if one is set, otherwise the input volume) and the current threshold is shown live in the slice views. Adjust it so that the vessel of interest is continuously highlighted between the seed points, without merging into neighbouring structures.

The following parameters control the evolution step and appear when `Show Advanced Segmentation Properties` is checked. Each ranges from -100 to 100.

- `less inflation <-> more inflation`: how fast the surface expands. Higher values fill the lumen faster but leak more easily. Default 0.
- `less curvature <-> more curvature`: how strongly the surface is smoothed. Higher values give a smoother, more tube-like result and resist leaking through small wall gaps. Default 70.
- `less attraction to gradient <-> more attraction to gradient`: how strongly the surface is attracted to gradient ridges, that is, the lumen wall. Default 50.
- `Iterations`: number of evolution iterations. Default 10. Increase it if the surface has clearly not reached the wall yet; the computation time grows proportionally.

`Restore Defaults` resets all input elements to their default values.

## Tips

- Start with the defaults and only change the evolution parameters if the result is visibly wrong. In practice, the threshold range and the placement of the seed points have a much larger effect on the result than the evolution weights.
- If the surface leaks outside the vessel, increase curvature, decrease inflation, and add `Stoppers` in the leaking region.
- If the surface stops short of the wall or of one of the seeds, increase inflation and the number of iterations, and check that the threshold range does not interrupt the lumen anywhere between the seeds.
- Segmenting a shorter branch at a time is faster and more robust than trying to capture a long, tapering vessel in one run.
- Cropping the input volume to the region of interest (using *Crop volume* module) considerably reduces computation time.
